# CSS and Web Platform Sources

Canonical sources to check for research on CSS and browser features.

| Source | URL | Use for |
| --- | --- | --- |
| CSSWG editor's drafts | <https://drafts.csswg.org/> | Current spec text; newer than the w3.org/TR snapshots |
| CSSWG issue archive | <https://lists.w3.org/Archives/Public/public-css-archive/> | Resolutions and open questions behind spec changes |
| HTML Living Standard | <https://html.spec.whatwg.org/multipage/> | HTML elements and attributes, such as `meta` names |
| MDN Web Docs | <https://developer.mozilla.org/> | Reference pages and Baseline badges |
| caniuse | <https://caniuse.com/> | Per-browser support versions and usage share |
| webstatus.dev | <https://webstatus.dev/> | Baseline status from web-features; renders with JavaScript, so fetch tools may get an empty page |
| Chromium blink-dev | <https://groups.google.com/a/chromium.org/g/blink-dev> | Intents to ship and their dates |
| WebKit Bugzilla | <https://bugs.webkit.org/> | Safari bugs and maintainer comments |
| Chrome Developers blog | <https://developer.chrome.com/blog> | Chrome feature announcements |
