# @just-web/toolkits

@just-web/toolkits is a toolkit for working with web technologies.

## Subpath

- **env** – `isDev`, a development flag resolved through export conditions
- **react.js** – React hooks and theme utilities
- **theme.js** – Theme store factories and composition
